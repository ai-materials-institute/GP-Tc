# Data Notes

This directory contains both training datasets and a small demo input for validating installation and running the prediction pipeline.

## Included Demo Dataset

- `Nd0.8Sr0.2NiO2_synth_doped.cif`: small example CIF file used in the demo command documented in the repository root `README.md`

## Larger Training Datasets

- `regression_data_histogram&symmetry.pkl`: regression training data
- `classification_data_3DSCnonsc_labeled.pkl`: classification training data

These larger files are used for model training and reproduction workflows rather than the lightweight installation demo.
