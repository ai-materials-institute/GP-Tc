# Replication Data

This directory contains the datasets bundled with the GP-Tc replication package.

## Included datasets

- `data/good_data_ord2_thre1%_with_symm.pkl`
- `data_09_26_2025/good_data_ord1_20250926.pkl`
- `data_09_26_2025/good_data_ordall_20250926.pkl`
- `data_10_6_25/regression_data_histogram&symmetry.pkl`
- `data_new_sg_featurization/good_data_symm_thre1%.pkl`

These files are used by the replication scripts documented in `src/GP_Models/sc_train_gp-main/replication/README.md`.

## Optional external dataset

The legacy `train_gp_new_sg_featurization.py` script also supports dataset `14` (`good_data_symm_33d_thre1%`), but that file is not bundled in this repository.
